# Conway's Game of Life

This project is a complete Python implementation of the classic cellular automaton: Conway's Game of Life.

## Features

- Native graphical interface built with Tkinter, dark theme.
- Optimized algorithm with toroidal edge handling (the grid wraps around itself).
- Interactive drawing: click or drag on the grid to place cells before starting the simulation.
- Preset shapes (Glider, Pulsar, Spaceship) selectable from a dropdown menu.
- Visual fade effect: cells change color based on how long they've been alive.
- Real-time counters for generation and population.
- Simulation speed control via a slider.
- Interactive buttons for Start / Pause, generating a Random grid, and Clearing the grid.

## Technologies

- Language: Python 3
- Graphics Library: Tkinter
